# SQBS 2.1 — Mac, Windows and Linux

SQBS 2.1 is the first release on all three platforms at once. Every version reads and writes the same tournament files, so a file can move between a Mac and a PC mid-tournament.

New in 2.1 everywhere: **scheduling and playoffs**, from Brian LeBlanc's [Quiz Bowl Statkeeper](https://github.com/bdleblanc81/qbstatkeeper). Brian designed these features and built the Swift framework they run on; thank you, Brian.

## Downloads

| Platform | File | Needs |
|---|---|---|
| Mac | `SQBS-2.1-mac.dmg` | macOS 12 or later, Apple Silicon or Intel |
| Windows | `SQBS-2.1-win-x64-setup.exe` | 64-bit Windows. Includes everything it needs |
| Linux | `sqbs_2.1_amd64.deb` | 64-bit Debian 12+ or Ubuntu 22.04+ |

Each file has a `.sha256` next to it to check the download.

**First launch.** SQBS is free and isn't signed with a paid certificate, so each system asks you to confirm once:
- **Mac:** right-click SQBS in Applications and choose **Open**. On macOS 15+, use **System Settings → Privacy & Security → Open Anyway**.
- **Windows:** if SmartScreen says "Windows protected your PC", click **More info**, then **Run anyway**.

## New

- **Schedule.** Rounds and rooms, schools and teams, pools, and random or round-robin schedules. Pick or lock any game by hand in the room-by-round grid. Moderators and scorekeepers with the rounds they're available, buzzer locations, and schedule checks.
- **Playoffs.** Playoff rounds, bracket format, tiebreakers and coin flips, seeds from the standings or by hand, and brackets fed by winners and losers.
- **Games waiting for a score.** Scheduled and playoff games appear in Game Entry with their round and teams filled in, and count nowhere until a score is entered. **Next Waiting** jumps to the next one; **New Round** checks the round is complete first.
- **Schedule reports.** Room matchups, team schedules, missing slots and buzzer locations, written with the web reports.

## Windows and Linux

The first release of the new SQBS for Windows and Linux: Tournament Setup, Game Entry, Reports, Settings, Merge (with the duplicate-game check), autosave backups, light and dark themes, and four text sizes. It replaces the [SQBS Plus](https://github.com/nick-pruitt-003/sqbs-plus) pre-release.

## Known limits

- **Older versions count waiting games.** SQBS Mac 2.0.1 and classic SQBS for Windows don't know about games waiting for a score. If they open a 2.1 file with a schedule, those games show as played, scored −1 to −1. Use 2.1 for scheduled tournaments, or enter every score first.
- Files with a schedule open fine in older versions otherwise. Saving there keeps the schedule only in SQBS Mac 2.0.1.
